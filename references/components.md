# 组件交互规格库

按"用户要干什么"选组件，不按"库里有什么"选。每个组件给：何时用、必备状态、常见坑。深挖说明放在高风险的几个组件后面。

## 快速选型

| 用户意图 | 首选 | 不要用 |
|---|---|---|
| 触发一个动作 | 按钮 | 带 `href="#"` 的链接 |
| 去另一个页面 | 链接 | 按钮 + `router.push` |
| 多选若干项 | 复选框组 / 多选列表 | 下拉多选（选项少时） |
| 单选且全部可见 | 单选按钮组 | 下拉 |
| 立即生效的二选一 | 开关 | 复选框 |
| 需要提交后才生效的二选一 | 复选框或单选 | 开关 |
| 从 5–15 个选项中选一个 | 下拉 | 单选组（占空间） |
| 从大量选项中搜索选择 | 组合框（可搜索下拉） | 超长下拉 |
| 同级内容切换 | 标签页 | 折叠面板 |
| 次要内容收起 | 折叠面板 / 详情展开 | 标签页 |
| 打断式确认 | 模态 | 页面跳转 |
| 轻量提示 | Toast / 行内提示 | 模态 |
| 补充说明 | Tooltip / Popover | 常驻文案（若不关键） |

## 1. 操作类

| 组件 | 何时用 | 必备状态 | 常见坑 |
|---|---|---|---|
| 主按钮 | 页面唯一主任务 | 默认/悬停/聚焦/按下/禁用/进行中 | 同页多个主按钮；进行中不禁用导致重复提交 |
| 次按钮 | 主任务的替代或取消 | 同上，视觉弱于主按钮 | 主次视觉权重相同，用户不知道点哪个 |
| 危险按钮 | 删除、注销、发布 | 默认/悬停/聚焦/按下/禁用/进行中 | 与普通按钮同色；默认焦点落在危险项 |
| 图标按钮 | 空间紧张且图标含义明确 | 五态 + 可访问名称 | 无 label/tooltip；图标含义靠猜 |
| 链接式按钮 | 行内动作（编辑、展开） | 悬停/聚焦/按下 | 无下划线也无颜色，发现不了 |
| 分裂按钮 | 主操作 + 少量变体 | 五态 + 菜单展开态 | 变体入口太隐蔽；主次动作颠倒 |

**按钮验收**：键盘 Tab 可达、Enter/Space 触发、按下 100 ms 内有视觉响应、进行中不可重复触发、禁用有原因说明。

## 2. 文本输入

| 组件 | 何时用 | 必备状态 | 常见坑 |
|---|---|---|---|
| 单行输入 | 短文本 | 默认/聚焦/已填/错误/禁用/只读/加载 | 用 placeholder 代替标签；错误只在顶部汇总 |
| 多行输入 | 长文本、备注 | 同上 + 字数统计 + 自适应高度 | 固定高度不可拉伸；超长内容无计数 |
| 密码输入 | 密码 | 同上 + 可见性切换 + 规则提示 | 规则提交后才知道；禁止粘贴 |
| 搜索框 | 站内/表内检索 | 默认/聚焦/有词/加载/无结果/清除 | 输入即请求无防抖；清空后不恢复列表 |
| 数字/步进器 | 有范围的数量 | 同上 + 边界值 + 长按连续 | 越界静默修正；单位不清 |
| 标签输入 | 多个短值（收件人、关键词） | 输入中/已添加/重复/超限/删除 | 回车行为不明确；重复项静默忽略 |
| 文件上传 | 上传附件/图片 | 选择前/上传中/成功/失败/重试/取消/预览/超限 | 无进度；失败无重试；拖拽区不可点击 |
| 富文本 | 需要格式的内容 | 输入/格式态/粘贴/图片上传/草稿 | 粘贴带样式污染；快捷键冲突；无字数限制 |
| 日期时间 | 预约、筛选范围 | 默认/聚焦/选择中/已选/范围/非法/时区 | 时区不说明；手输格式不校验；移动端键盘不匹配 |

**输入验收**：每个字段有可见标签；失焦校验、提交汇总；错误贴近字段且不清空输入；自动填充不被破坏。

## 3. 选择控件

| 组件 | 何时用 | 必备状态 | 常见坑 |
|---|---|---|---|
| 复选框 | 多选，或需提交的单个布尔 | 未选/选中/部分选中/禁用/错误 | 父级三态缺失；点整行不生效 |
| 单选组 | 少量互斥选项，全部可见 | 未选/选中/禁用/错误 | 选项超过 7 个仍用单选组 |
| 开关 | 立即生效的二选一 | 开/关/禁用/进行中/失败回滚 | 需要"保存"才生效；无即时反馈 |
| 下拉选择 | 5–15 项、无需对比 | 收起/展开/悬停/已选/禁用/空/加载 | 选项过多；无搜索；选中后菜单不关 |
| 组合框 | 大量选项或需搜索 | 同上 + 输入/过滤/无匹配/自由输入 | 键盘上下键不工作；过滤后高亮错位 |
| 多选下拉 | 多选且空间有限 | 同上 + 已选计数 + 清除全部 | 已选项不可见；超出数量无提示 |
| 分段控件 | 2–5 个互斥视图切换 | 选中/悬停/聚焦/禁用 | 与标签页混用；选中态仅靠颜色 |
| 滑块 | 连续值、可粗调 | 拖动/键盘/边界/禁用 | 无法精确输入；无当前值显示 |
| 评分/星级 | 主观打分 | 悬停预览/已选/清除/禁用 | 无法撤销评分；半星歧义 |

## 4. 容器与浮层

| 组件 | 何时用 | 必备状态 | 常见坑 |
|---|---|---|---|
| 模态 | 必须打断的确认；字段很少且离开会丢上下文的短表单 | 打开/关闭/Esc/焦点管理/滚动锁/加载/错误 | 背景仍可 Tab；关闭丢输入；多层模态叠加；长表单/多步/需对照页面的任务被塞进模态 |
| 抽屉 | 侧向详情、复杂表单 | 同上 + 可调整宽度 | 遮住主内容却无关闭手势提示 |
| 弹出层 Popover | 轻量操作/信息 | 打开/关闭/点外关闭/Esc | 点击内部误关闭；定位越界 |
| Tooltip | 图标释义、截断补充 | 悬停/聚焦/延迟出现 | 触屏不可用；内容含链接（不可点） |
| 下拉菜单 | 一组操作 | 打开/关闭/键盘导航/禁用项 | 无方向键；点击后不关闭；危险项无区分 |
| Toast | 非阻塞结果通知 | 出现/自动消失/手动关闭/操作按钮 | 消失太快；无 aria-live；承载必须确认的信息 |
| 横幅 Banner | 全局状态（离线、试用到期） | 出现/关闭/重现策略 | 可关闭后永久消失，用户忘了状态 |
| 标签页 | 同级视图切换 | 选中/悬停/聚焦/禁用/加载/空 | 把必读内容做成标签；标签过多溢出 |
| 折叠面板 | 次要内容收起 | 展开/收起/禁用/多开或单开 | 用户需要读全部内容时仍折叠；无展开全部 |

**浮层验收**：模态用原生 `<dialog>`+`showModal()` 或 `role="dialog"`+`aria-modal`；背景**兄弟节点** `inert`（`aria-hidden` 不是替代，它不拦 Tab）；Esc/关闭按钮/遮罩按未保存策略处理；焦点进入与归还；小屏不遮挡关键操作。细节见 states.md §8。

## 5. 数据与列表

| 组件 | 何时用 | 必备状态 | 常见坑 |
|---|---|---|---|
| 表格 | 多列对比、批量操作 | 加载/空/错误/排序/筛选/选中/分页/列宽/固定列 | 分页与筛选状态不同步；选中跨页丢失 |
| 列表 | 同类条目流 | 加载/空/错误/加载更多/到底/选中 | 无限滚动无到底提示；返回丢位置 |
| 卡片 | 图文混合、可点整体 | 悬停/聚焦/选中/加载/禁用 | 整卡可点但内部有次级按钮（点击冲突） |
| 树 | 层级数据 | 展开/收起/选中/半选/加载子级/空 | 展开无加载态；层级过深无面包屑 |
| 进度条 | 可预估时长的任务 | 进行中/暂停/失败/完成/不确定态 | 进度回退；完成不刷新数据 |
| 骨架屏 | 结构可预期的加载 | 加载/加载完成替换 | 与真实布局不同构，内容到达时跳动 |
| 空状态 | 无数据 | 首次空/清空空/无结果/无权限 | 只写"暂无数据"，没有下一步 |
| 分页 | 长列表、可回访 | 首页/末页/当前页/跳转/禁用 | 页码过多不折叠；筛选后不重置到第 1 页 |

**表格验收**：排序/筛选/分页可组合且状态可恢复；批量操作显示影响范围；空与错误可区分。

## 6. 流程控件

| 组件 | 何时用 | 必备状态 | 常见坑 |
|---|---|---|---|
| 步骤条 | 线性多步流程 | 当前/已完成/未开始/错误/可返回 | 不能回退；步骤数与实际不符 |
| 向导 | 长表单分步 | 同上 + 草稿 + 中途离开提示 | 每步都校验但不告诉总数；最后一步才报错 |
| 筛选器 | 结果集收敛 | 默认/已选/清空/无结果/计数 | 选项与结果不对应；无"已应用"提示 |
| 批量操作 | 多选后统一处理（见下） | 未选/部分选/全选/进行中/部分成功/结果 | 不显示影响数量；无撤销；逐条补数据与导入无结构 |
| 命令面板 | 高频键盘用户 | 关闭/搜索/高亮/无结果 | 无快捷键提示；与输入框焦点冲突 |
| 通知中心 | 异步事件汇总 | 未读/已读/空/全读 | 已读不可撤销；打扰无分级 |

## 深挖：模态

- **选实现**：原生 `<dialog>` + `showModal()`（自带模态语义与焦点约束）优先；自定义则 `role="dialog"` + `aria-modal="true"` + `aria-labelledby`。
- 打开：焦点移到标题或第一个可交互元素；背景**兄弟节点** `inert`（不要把 dialog 的祖先设为 inert）；滚动锁。
- 关闭：Esc / 关闭按钮 / 点遮罩，具体按 states.md §8 的「未保存内容」表；关闭后焦点回到触发元素。
- 内容：必须有可访问名称（`aria-labelledby` 指向可见标题）；危险操作确认时默认焦点放在安全项。
- 别用模态承载：多步注册、长表单、需要对照页面内容的任务；短表单仅在字段很少且离开会丢上下文时用。

## 深挖：文件上传

- 选择前：说明格式、大小上限、数量上限。
- 上传中：单项进度、可取消、可继续添加。
- 失败：单条失败不影响其他；给出原因与重试。
- 完成：可预览、可删除、可替换。
- 拖拽：整块区域可点击，拖入时有明确高亮；**必须提供不用拖拽的单指针替代**（点击选择文件 + 按钮移动、上下移按钮等，WCAG 2.2 SC 2.5.7）。

## 深挖：表格

- 选中跨页：明确"已选 N 项（跨页）"，或提供"选择全部 M 项"。
- 排序与筛选：改变后回到第 1 页，或明确保持当前页。
- 列过多：优先固定首列与操作列，其余横向滚动，滚动时表头固定。
- 加载：首屏骨架、翻页保留旧数据 + 局部 loading，避免整表闪白。
- 空与错：区分"没有数据"与"加载失败"，后者给重试。

## 深挖：批量操作

批量不是「一个按钮作用于 N 条」，先分清三型：

| 型 | 例子 | 入口与输入 | 校验 | 结果界面 |
|---|---|---|---|---|
| 统一动作 | 批量删除、批量归档 | 工具栏 + 确认 | 行级可选性 | 部分失败分组、重试失败项 |
| 逐条补数据 | 批量发货填运单号、批量改价 | 行内编辑 / 抽屉 / 侧滑表单 | 逐行校验，允许暂存草稿 | 每行状态 + 失败原因，可只重试失败行 |
| 文件导入 | Excel 导入订单/商品 | 上传 → 字段映射 → 预览 | 预览阶段校验、错误行下载 | 导入结果：成功/失败/跳过，失败清单可导出 |

**行级可选性**：每行三态——可选 / 不可选（必须给出原因，如「已发货」）/ 暂不可判定（加载中）；不可选行显示禁用 + 原因，不要隐藏。全选要说明范围（本页 / 全部筛选结果）与计数（「已选本页 18 单（共 20 单，2 单不可选）」）。

**批量结果**：成功 N / 失败 M / 跳过 K；失败按原因分组；提供「重试失败项」「导出失败清单」「返回列表」；刷新列表后保持失败行可见（或高亮）；不要用一个笼统的「操作完成」盖住部分失败。

## 深挖：搜索

- 输入防抖 200–300 ms（经验值）；请求可取消；丢弃过期响应。
- 中文/日文/韩文输入：`compositionstart` 到 `compositionend` 之间不触发搜索，或检查 `event.isComposing`；回车/点搜索按钮立即请求，不防抖。
- 无结果：给替代（放宽条件、浏览分类、检查拼写），而不是一句"无结果"。
- 搜索建议：键盘上下选择、回车执行、Esc 关闭；建议要有来源说明。
- 结果页：显示查询词与结果数，允许一键清除筛选。

## 数量与长度边界（经验值，来自 Ant Design 规范与常见实践）

| 控件 | 边界 | 说明 |
|---|---|---|
| 顶部导航 | 一级类目 2–7 个 | 标题中文 2–6 字、英文 4–15 字符 |
| 标签页 | 标题中文 2–6 字 | 用于同级切换，不用于顺序阅读 |
| 单选组 | 2–5 个选项 | 选项全部可见、需要对比 |
| 下拉 | 选项多于 5 个 | 选项少且需要对比时用单选组 |
| 步骤条 | 2–5 步，每步 ≤12 字 | 步骤多或动态变化用竖向 |
| 面包屑 | 3 级以内，最多 5 级 | 当前页已能说明位置时不必用 |
| 轮播 | 3–5 个 | 必须有「几张、往哪翻」的暗示 |
| 卡片 | 一行不超过 4 个 | 信息过长要截断并给完整入口 |
| 分页 | 10 页以内可用简易样式 | 条目多时允许自定义每页条数 |

## 数据格式

- 数值默认千分位；百分比保留合理精度；表格里的金额、数量右对齐。
- 金额用「货币符号 + 数字」（如 CNY1,123.00）。
- 时间分绝对与相对：精确检索用 `yyyy-mm-dd`；消息/通知用「刚刚 / N 分钟前」。
- 空数据统一用 `--` 或 `-`；加载用骨架屏。
- 敏感数据脱敏：姓名保留首尾、手机保留前 3 后 4、金额可全脱敏。
